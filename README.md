# 🛡️ Secure Network Asset Discovery and Vulnerability Assessment System

A graduation project from the Department of Computer Science and Cyber Security, Faculty of Engineering and Technology, Birzeit University.

🏆 **Ranked 5th place at the Secure Digital Innovation Competition 2026.**

## 📖 Overview

Small and medium-sized enterprises (SMEs) often lack the resources to fully secure their internet-facing assets, leaving them exposed to cyberattacks. This project addresses that gap by combining:

- **Attack Surface Management (ASM)** – to continuously discover internet-facing assets and their vulnerabilities.
- **Continuous Threat Exposure Management (CTEM)** – to prioritize, validate, and reduce false positives among detected vulnerabilities.
- **Attack Graph Generation** – to model how chained vulnerabilities can form realistic attacker paths across interconnected assets.

The system presents its findings through an interactive dashboard and structured security reports, helping organizations move from simple vulnerability scanning to proactive, risk-based security decision-making.

## ✨ Key Features

- Automated discovery of externally exposed assets (IPs, domains, subdomains, services)
- Continuous vulnerability scanning and validation using CTEM stages
- Attack graph generation with ranked, realistic attack paths
- Vulnerability prioritization and risk scoring
- Interactive dashboard with reports and statistics

## 🛠️ Tech Stack

- **Scanning tools:** Nmap, MASSCAN, Subfinder, DNSX, HTTPX, Nuclei, OpenVAS, CISA
- **Attack graph engine:** Python, NetworkX, CVE dataset
- **Backend:** PHP, Python
- **Frontend:** HTML, CSS, JavaScript
- **Database:** MySQL
